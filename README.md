# SPIKE
An Energy-Aware Autonomous Taskbot with Real-Time Navigation Control using a Low-Cost FPGA-Based Spiking Neural Network

This work investigates advantages to energy efficiency and responsiveness brought by an FPGA-based SNN hardware acceleration for control decisions in an autonomous task-specific robot vehicle (taskbot) application, as opposed to running the same algorithm by programming an on-board general purpose CPU.
